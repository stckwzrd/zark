`comptime` выполняет кусок вашей программы **во время компиляции** и кладёт результат в бинарник как константу. Это тот же язык с теми же функциями, циклами и стандартной библиотекой: никакого второго «языка макросов» нет.

```zark run
i64 fib(i64 n) {
    if (n < 2) { return n; }
    return fib(n - 1) + fib(n - 2);
}

void main() {
    println(comptime fib(30));
}
```

Вызова `fib(30)` в бинарнике нет. Компилятор собрал маленькую программу, запустил её, прочитал ответ и вставил число `832040`.

## Что может быть значением comptime

Результат должен быть простыми данными: число, `bool`, enum, `str`, а также массив или структура из них. Указатель или срез чужих данных не имеет смысла в другом процессе, поэтому они отклоняются:

```zark error
i64* nothing() { return null; }

void main() {
    const auto x = comptime nothing();
}
```

## Что можно использовать внутри comptime

Функции, константы, типы и другие значения `comptime`. Нельзя использовать локальные переменные и параметры типов шаблона: значений для них ещё нет:

```zark error
void main() {
    auto n = 5;
    println(comptime n + 1);
}
```

## Таблицы

Главное применение — таблица, которую иначе пришлось бы набирать руками или заполнять при запуске. Функция, строящая её, — обычная функция:

```zark run
u32[256] make_crc() {
    u32[256] t;
    for (auto i : 0..256) {
        u32 c = i as u32;
        for (auto k : 0..8) {
            if (c & 1 == 1) { c = 0xEDB88320 ^ (c >> 1); } else { c = c >> 1; }
        }
        t[i] = c;
    }
    return t;
}

const auto CRC = comptime make_crc();

u32 crc(str s) {
    u32 c = 0xFFFFFFFF;
    for (auto b : s) { c = CRC[((c ^ b as u32) & 0xFF) as i64] ^ (c >> 8); }
    return ~c;
}

void main() {
    println(crc("123456789"));
}
```

Таблица лежит в данных программы только для чтения. `CRC[i]` читает один элемент и не копирует таблицу.

Структуры и строки работают так же:

```zark run
struct Limits { i64 max_users; f64 ratio; bool strict; }

Limits defaults() { return Limits{ .max_users = 100, .ratio = 0.75, .strict = true }; }
str banner() { return "zark"; }

void main() {
    const auto l = comptime defaults();
    println(l.max_users, l.ratio, l.strict, comptime banner());
}
```

## Проверка фактов при сборке

`comptime` на верхнем уровне вычисляется до сборки программы. Если он паникует или не проходит `assert`, компиляция останавливается. Это статическая проверка:

```zark error
struct Header { u8 kind; i64 length; }

comptime assert(sizeof(Header) == 9);

void main() {}
```

Сообщение `assertion failed` приходит из самого запуска при компиляции, а за ним идёт строка с `comptime`.

Внутри функции `comptime` на операторе, который ничего не возвращает, делает то же самое в этой точке.

## Правила и цена

- **Это правда выполняет ваш код.** Функция в `comptime` может читать файлы и печатать, как любая другая. Она работает с проверками обычной сборки, поэтому переполнения, выходы за границы и деление на ноль — паники, которые останавливают компиляцию с сообщением.
- **Каждый `comptime` стоит одной дополнительной компиляции** программы (около десятой доли секунды для небольшой). Одно и то же выражение выполняется один раз за сборку, сколько бы раз ни использовалась его константа.
- **Не внутри интерполяции строк.** Пишите `const auto x = comptime f();` и используйте `x` в строке.
- **Шаблоны.** `sizeof(T)` компилятор и так знает, поэтому для него `comptime` не нужен; `comptime` не видит `T`.
