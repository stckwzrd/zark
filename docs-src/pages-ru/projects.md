Для начала хватает одного файла. Когда программа разрастается до нескольких файлов, кода на C или чужих библиотек, опишите её в `vibe.toml`, и `vibe run`, `vibe build` и `vibe test` будут работать без имени файла.

```sh
vibe new hello        # hello/vibe.toml, hello/src/main.vibe, hello/.gitignore
cd hello
vibe run              # компилирует src/main.vibe и запускает
vibe run -- --name me # аргументы после -- получает программа
vibe build --release  # пишет build/hello
vibe test             # блоки test из src/main.vibe и из всех файлов в tests/
```

Команды ищут `vibe.toml` в текущем каталоге и во всех каталогах выше, поэтому работают и из `src/sub/`. Файл, явно названный в командной строке (`vibe run tools/gen.vibe`), внутри проекта всё равно получает зависимости, исходники C и библиотеки проекта.

## `vibe.toml`

```text
[package]
name = "app"
version = "0.1.0"
main = "src/main.vibe"      # что компилируют run и build (по умолчанию src/main.vibe)
lib = "src/lib.vibe"        # что загружает `import "app"` в проектах, которые зависят от этого

[build]
sources = ["c/fast.c"]      # файлы C или C++, которые компилируются и линкуются
libs = ["ssl", "m"]         # линкуются как -lssl -lm
flags = ["-O"]              # флаги по умолчанию; командная строка добавляет свои
out = "build/app"           # куда vibe build пишет программу (по умолчанию build/NAME)

[dependencies]
utils = { path = "../utils" }
json5 = { git = "https://github.com/someone/json5.vibe", rev = "v1.2" }
```

Формат — небольшая часть TOML: секции, `key = value`, строки, целые, логические значения, списки, встроенные таблицы и комментарии `#`. Ошибка сообщается с номером строки: `vibe.toml:2: error: unterminated string`.

## Зависимости

Зависимость импортируется по имени:

```vibe fragment
import "utils" as u;            // lib-файл зависимости
import "utils/strings" as us;   // файл рядом с ним (.vibe можно не писать)
```

- Зависимость `path` указывает на каталог на диске.
- Зависимость `git` клонируется в `.vibe/deps/NAME`, когда она впервые нужна команде (`rev` — тег или ветка). Удалите каталог, чтобы скачать заново.
- Зависимость со своим `vibe.toml` приносит с собой свои зависимости, исходники C и библиотеки. Без манифеста её lib-файл — `src/lib.vibe` или `lib.vibe`.
- Импорты, начинающиеся с `./` или `../`, всегда относительные, поэтому имя зависимости их не заслоняет.

Языковой сервер читает тот же манифест, так что импорты зависимостей находятся и в редакторе.
