В Vibe четыре способа дать значению имя: `let`, `var`, `const` и глобальная `var`. Выбор между ними — это выбор между «можно менять» и «нельзя», который проверяет компилятор.

## `let` — неизменяемая привязка

```vibe run
fn main() {
    let x = 10
    let name = "Vibe"
    let pi: f64 = 3.14159
    println(x, name, pi)
}
```

Тип можно не указывать: он выводится из значения. Явный тип нужен, когда значение само по себе его не определяет (например, литерал `5` может быть любым целым) или когда вы хотите зафиксировать тип:

```vibe run
fn main() {
    let a = 5
    let b: u8 = 5
    let c: f32 = 5.0
    println(sizeof(i64), a, b, c)
}
```

Менять `let` нельзя:

```vibe error fragment
let x = 1
x = 2
```

```vibe error fragment
let x = 1
x += 1
```

## `var` — изменяемая переменная

```vibe run
fn main() {
    var count = 0
    count = 5
    count += 1
    count *= 2
    println(count)
}
```

Если `var` нигде не меняется, компилятор молчит: предупреждений о неиспользуемых переменных нет.

## Инициализация нулями

Переменная без начального значения заполняется нулями (нулевые биты). Это касается и `let`, и `var`, и целых, и массивов, и структур:

```vibe run
struct P { x: i64, name: str }

fn main() {
    var n: i64
    var f: f64
    var b: bool
    var s: str
    var arr: [4]i32
    var p: P
    println(n, f, b, s.len, arr)
    println(p.x, p.name.len)
}
```

Пустая строка — это нулевой указатель и длина 0; пустой указатель — `null`. Поэтому «забыть» инициализировать переменную нельзя: чтение всегда определено.

> **Совет.** Если вы пишете `let x: T` без значения, то `let` бесполезен — вы ничего не сможете присвоить. Для этого нужен `var`.

## Постоянство «насквозь»

`let` запрещает не только присвоить сам `let`, но и менять поля структуры и элементы массива **через него**:

```vibe error
struct P { x: i64 }

fn main() {
    let p = P{ x: 1 }
    p.x = 2
}
```

```vibe error fragment
let a = [1, 2, 3]
a[0] = 5
```

Чтобы менять содержимое, объявляйте `var`:

```vibe run
struct P { x: i64 }

fn main() {
    var p = P{ x: 1 }
    p.x = 2
    var a = [1, 2, 3]
    a[0] = 5
    println(p.x, a)
}
```

Зато то, что лежит **за указателем или срезом**, `let` не замораживает: ограничение касается только самой привязки.

```vibe run
fn bump(xs: []i64) {
    for i in 0..xs.len { xs[i] += 1 }
}

fn main() {
    var data = [1, 2, 3]
    let view = data[..]
    bump(view)
    view[0] = 100
    println(data)
}
```

Здесь `view` объявлен через `let`, но `view[0] = 100` работает: срез указывает на изменяемый `data`. Функция `bump` получила срез и поменяла данные вызывающего.

Параметры функций неизменяемы, как `let`. Хотите менять локально — заведите копию через `var`, либо принимайте указатель / срез.

## Область видимости

Переменная живёт до конца блока `{ ... }`, где объявлена. В одном блоке одно имя дважды объявить нельзя:

```vibe error fragment
let x = 1
let x = 2
```

Во вложенном блоке имя можно **перекрыть** (shadowing); после выхода из блока снова видна внешняя:

```vibe run
fn main() {
    let x = 1
    {
        let x = 2
        println("внутри {x}")
    }
    println("снаружи {x}")
    for i in 0..2 {
        let x = i * 10
        println(x)
    }
}
```

Переменные цикла (`for i in ...`) тоже живут только внутри цикла.

### Не называйте переменную как функцию

Локальная переменная заслоняет функцию с тем же именем, и вызов дальше в блоке становится невозможным:

```vibe error
fn main() {
    let max = 5
    println(max(1, 2))
}
```

 Не называйте переменные `min`, `max`, `abs`, `sort` и т. п. — это функции [стандартной библиотеки](stdlib.md).

## `const` — константа времени компиляции

`const` вычисляется при компиляции и подставляется по месту. У константы нет адреса, и её нельзя изменить.

```vibe run
const A = 3
const B = A * 2 + 1
const NAME = "vibe"
const RATE = 1.5
const MASK = 0xff & 0x0f

fn main() {
    var arr: [B]i64
    println(A, B, NAME, RATE, MASK)
    println(arr.len)
}
```

Если константа нужна как размер массива, она обязана быть вычислима при компиляции: числа, арифметика над ними и другие константы. Если в инициализаторе вызов функции, `const` превращается в «выражение, которое подставляется при каждом использовании» и пересчитывается каждый раз:

```vibe run
var n = 0

fn next() i64 {
    n += 1
    return n
}

const K = next()

fn main() {
    println(K, K, K)
}
```

> **Ловушка.** Это не то, чего ждут от константы. Не кладите в `const` вызовы функций с побочными эффектами; для таких значений заведите `let`.

Присваивать константе нельзя:

```vibe error
const K = 5

fn main() {
    K = 6
}
```

Тип можно указать явно: `const LIMIT: u8 = 200`. Без него число получает тип по контексту использования.

> **Примечание.** Полноценных вычислений при компиляции (`comptime`) пока нет, они в [планах](how-it-works.md#что-дальше).

## Глобальные переменные

Объявленная на верхнем уровне `var` — глобальная изменяемая переменная. Инициализатор обязателен и должен быть константным выражением: число, арифметика над числами, `true`/`false`, `null`. Другую глобальную переменную в инициализаторе использовать нельзя.

```vibe run
var calls = 0
var limit: i64 = 100
var total: i64 = 2 + 3
var ready = true

fn hit() {
    calls += 1
}

fn main() {
    hit()
    hit()
    hit()
    println(calls, limit, total, ready)
}
```

> **Ловушка.** Глобальная переменная типа `str` с инициализатором (`var name: str = "x"`) сейчас остаётся пустой строкой. Без типа (`var name = "x"`) компилятор выдаёт ошибку «not a compile-time constant». Если нужна глобальная строка, объявите `var name: str = ""` и присвойте значение в начале `main`.

У глобальной переменной можно взять адрес, она хранится в памяти программы всё время работы.

Глобальные `var` — это общее изменяемое состояние. Используйте их экономно: чаще лучше передать значение или указатель параметром.

## Порядок объявлений

Порядок функций, структур и констант на верхнем уровне не важен: вызывать функцию можно раньше, чем она объявлена в файле.

```vibe run
fn main() {
    println(later(5))
}

fn later(x: i64) i64 { return x + LIMIT }

const LIMIT = 100
```
