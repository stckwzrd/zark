Лексика

Здесь описано, из каких кусочков состоит исходный текст: комментарии, числа, строки, имена и правило «конца оператора».

#Файл и точка входа

Исходный файл — обычный UTF-8 текст с расширением .vibe. Программа начинается с функции main. Она может возвращать ничего, i32 (код выхода) или !void (ошибку, которая завершит программу).

void main() {
    println("минимальная программа");
}
Вывод
минимальная программа

Код выхода можно вернуть числом:

i32 main() {
    println("выходим с кодом 3");
    return 3;
}
Выводкод выхода 3
выходим с кодом 3

#Комментарии

Есть два вида: строчный // и блочный /* ... */.

void main() {
    // строчный комментарий идёт до конца строки
    const auto a = 1 /* блочный можно вставить прямо в выражение */ + 2;
    /*
       блочный может занимать
       несколько строк
    */
    println(a);
}
Вывод
3

Примечание. Блочные комментарии не вкладываются друг в друга: первый же */ закрывает комментарий.

#Конец оператора

Каждый оператор заканчивается точкой с запятой, как в C++. После закрывающей } блока, функции, struct, enum, union, if, while, for и match она не нужна.

Оператор можно переносить как угодно: конец определяется только ;.

i64 sum3(i64 a, i64 b, i64 c) { return a + b + c; }

void main() {
    const auto total = 1
        + 2
        + 3;
    const auto r = sum3(
        10,
        20,
        30
    );
    const auto xs = [
        1,
        2,
        3
    ];
    println(total, r, xs);
}
Вывод
6 60 [1, 2, 3]

Если забыть ;, компилятор укажет на токен, где оператор должен был закончиться:

void main() {
    const auto total = 1
    println(total);
}
Вывод компилятора
main.vibe:3: error: expected ';' (near 'println')
    3 |     println(total);
      |     ^

Несколько операторов можно уместить в одну строку:

void main() {
    auto x = 1; x += 1; x *= 10;
    println(x);
}
Вывод
20

else можно поставить как на одной строке с }, так и на следующей:

void main() {
    const auto n = 5;
    if (n > 3) {
        println("больше");
    }
    else {
        println("не больше");
    }
}
Вывод
больше

Формат vibe fmt всегда пишет } else { в одну строку, см. инструменты.

#Идентификаторы

Имя состоит из латинских букв, цифр и _, не начинается с цифры. Регистр различается. Имена, начинающиеся с двух подчёркиваний (__find, __qsort), используются внутри стандартной библиотеки: свои так не называйте.

Ключевые слова нельзя использовать как имена:

fn const static template struct union enum type import as extern export
if else while for match return break continue defer errdefer
test is orelse catch sizeof alignof true false null nullptr error

Примечание. auto, this и Self — не ключевые слова в строгом смысле, но имеют особый смысл: auto вместо типа, this и Self внутри методов.

#Целые литералы

Запись Значение
42 десятичное
0xff шестнадцатеричное, 255
0b101 двоичное, 5
0o17 восьмеричное, 15
1_000_000 _ — разделитель разрядов, на значение не влияет 
void main() {
    println(42, 0xff, 0b101, 0o17, 1_000_000);
    println(0xDEAD_BEEF, 0b1111_0000);
}
Вывод
42 255 5 15 1000000
3735928559 240

Тип целого литерала берётся из контекста; если контекста нет, это i64:

void main() {
    const auto a = 7;
    const u8 b = 200;
    const i16 c = -5;
    u32 d = 4000000000;
    println(a, b, c, d);
}
Вывод
7 200 -5 4000000000

Литерал должен помещаться в свой тип, иначе это ошибка компиляции:

void main() {
    const u8 b = 300;
    println(b);
}
Вывод компилятора
main.vibe:2: error: integer literal 300 does not fit in 'u8'; use a wider type or an explicit 'as'
    2 |     const u8 b = 300;
      |                  ^

u8 — 0..255, i8 — -128..127. Чтобы обрезать намеренно, пишите as: 300 as u8 даёт 44.

#Дробные литералы

void main() {
    println(3.14, 1e9, 2.5e-3, 1_000.5);
    const f32 f = 0.1;
    println(f);
}
Вывод
3.14 1e+09 0.0025 1000.5
0.1

Литерал вида 1e9 — дробный (f64), хотя записан без точки. Тип по умолчанию f64, в контексте f32 литерал становится f32.

#Символы

Символ в одинарных кавычках — это число типа u8 (код байта). Юникод-символы вне ASCII в одинарные кавычки не помещаются: они занимают несколько байт.

void main() {
    const auto c = 'A';
    println(c, c + 1, (c + 1) as u8 == 'B');
    println("{c:c} {'z':c}");
    const auto digit = '7' - '0';
    println(digit);
}
Вывод
65 66 true
A z
7

Печатается число, если не попросить формат :c. Подробнее о форматах — в строках.

#Строковые литералы

Строка в двойных кавычках имеет тип str: это срез байтов { ptr, len } (см. типы). Литерал лежит в памяти программы и заканчивается нулевым байтом, поэтому его можно напрямую отдавать в C.

#Escape-последовательности

Запись Что означает
\n перевод строки
\t табуляция
\r возврат каретки
\0 нулевой байт
\e символ ESC (0x1b), для цветов в терминале
\\ обратная косая черта
\" двойная кавычка
\' одинарная кавычка
\{ литеральная {
\} литеральная } 
void main() {
    println("строка 1\nстрока 2");
    println("колонка\tколонка");
    println("кавычки: \" и \\");
    println("скобки: \{ и \}");
}
Вывод
строка 1
строка 2
колонка	колонка
кавычки: " и \
скобки: { и }

#Многострочные строки

Строковый литерал может содержать настоящий перевод строки. Он попадёт в значение как есть, вместе с отступами:

void main() {
    const auto text = "первая
вторая
третья";
    println(text);
    println(text.len);
}
Вывод
первая
вторая
третья
38

#Интерполяция

В "..." выражение в фигурных скобках вычисляется и подставляется. Скобки — часть формата, поэтому литеральные нужно удваивать: {{ и }} (или экранировать \{).

void main() {
    const auto a = 6;
    const auto b = 7;
    println("{a} * {b} = {a * b}");
    println("{{a}} — это не подстановка");
    println("{a + b > 10} {a:03}");
}
Вывод
6 * 7 = 42
{a} — это не подстановка
true 006

Интерполяция — не вызов функции и ничего не выделяет в куче: компилятор превращает строку в формат для printf. Подробности в разделе строки и форматирование.

Ловушка. Забытая {{ — частая ошибка при печати JSON или C-кода: "{"key": 1}" ломается, нужно "{{\"key\": 1}}".

#Булевы значения и null

true и false — значения bool. null — «пустой указатель» и «пустой ?T», подробнее в ошибках и опциональных значениях.
